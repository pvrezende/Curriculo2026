# Currículo 2026 — Paulo Rezende

Projeto de currículo profissional em HTML, CSS e JavaScript, com versões específicas para áreas de atuação:

1. Full Stack
2. Back-end Node.js
3. Python / IA / Visão Computacional
4. Java / Spring Boot
5. Mobile React Native

## Objetivo

Criar um currículo moderno, compatível com ATS e pronto para exportação em PDF, mantendo uma estrutura visual limpa, profissional e alinhada ao padrão Vitae.

## Arquivos

- `index.html` → estrutura principal do currículo
- `style.css` → estilos visuais, responsividade e impressão/PDF
- `reset.css` → reset básico
- `main.js` → troca de perfil, idioma, tema e impressão
- `assets/img/perfil.png` → foto profissional do currículo

## Como testar

1. Abra a pasta no VS Code.
2. Use a extensão Live Server ou abra `index.html` no navegador.
3. Escolha a versão do currículo no seletor.
4. Clique em **Baixar / Imprimir PDF**.
5. Na janela de impressão, escolha **Salvar como PDF**.

## Versões disponíveis

- Full Stack: currículo principal
- Back-end Node.js: foco em APIs, integrações, banco de dados e cloud
- Python / IA: foco em TuboVision, OpenCV, FastAPI e visão computacional
- Java / Spring Boot: foco em Smart Pet e stack enterprise
- Mobile React Native: foco em Controle de Gastos, Expo, JWT e APIs REST

## Recomendações

- Gere um PDF separado para cada perfil.
- Nomeie os arquivos finais conforme a vaga.
- Mantenha LinkedIn e GitHub alinhados ao currículo principal.
